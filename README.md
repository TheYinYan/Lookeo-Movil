## 🎯 Objetivo

Desarrollar la versión móvil de Lookeo, una aplicación orientada a la gestión del armario personal y la creación de conjuntos.

Entre las funcionalidades previstas para la aplicación móvil se encuentran:

- Subir fotografías de prendas de ropa.
- Clasificar las prendas por tipo, color, temporada y ocasión.
- Obtener sugerencias de combinaciones de conjuntos.
- Guardar y consultar conjuntos favoritos.
- Consultar y organizar las prendas del armario virtual.

El **probador virtual mediante inteligencia artificial** está previsto para la versión web de Lookeo.

Este repositorio contiene el cliente móvil. El backend y la API REST se gestionan en un repositorio independiente.

## 🛠️ Tecnologías

- **Lenguaje:** Kotlin.
- **Interfaz de usuario:** Jetpack Compose.
- **Entorno de desarrollo:** Android Studio.
- **Construcción y gestión de dependencias:** Gradle.
- **Interfaz y estado:** componentes composables y gestión de estado de la aplicación.
- **Comunicación con el backend:** integración con la API REST del proyecto.

## 🚀 Cómo ejecutar el proyecto

### Requisitos previos

- Android Studio.
- SDK de Android compatible con la configuración del proyecto.

### Instalación

1. Clona el repositorio:

   ```bash
   git clone https://github.com/TheYinYan/Lookeo-Movil.git
   ```

2. Abre el proyecto en Android Studio.
3. Espera a que finalice la sincronización de Gradle.
4. Ejecuta la aplicación en un emulador o dispositivo Android compatible.
